# Competitor Analysis (limited, honest scope)

Only a handful of live searches were possible in this session. Results were dominated by vendor-authored listicles and job posts. Treat this as directional, not a full audit. No backlink, traffic or SERP-position tools were available.

## Observed (live searches, 2026-10-12)
**AI agent development India** — vendors: AppSquadz, Ampcome, Vegavid, Promatics, Debut Infotech. Pattern: a service page ("Agentic AI development services") plus many blog "Top 10 AI agent companies in India 2026" posts; claims industry depth (finance, logistics, healthcare, retail, manufacturing).
**Web development Coimbatore** — ColorWhistle (city landing page + directory listicle), BUD India, Websome, DevToMark (DesignRush profile), Pepy Technologies, PG Softwares. Pattern: `/web-development-company-<city>` pages, directory profiles (DesignRush, Clutch, YourStory), review-based trust.
**Playwright/test automation India** — SERP is mostly job listings and freelance gigs (Fiverr). Few dedicated agency service pages surfaced: a real gap for a focused page.
**Brand "myloginn"** — SERP shows MyLogin (Wonde school SSO, LAUSD, Minecraft plugin). MyLoginn does not appear for its own name in that search.

## Gaps
| Type | Gap |
|---|---|
| Keyword | AI agent / agentic AI / AI automation, Playwright and API testing service queries; MyLoginn had no page |
| Content | No "how much does X cost in India" explainers, no case studies, no comparison/FAQ content |
| Service | AI, testing (now added). UI/UX, cloud/DevOps, SaaS: no pages; add only when delivery capacity is real |
| Location | Competitors use city pages. MyLoginn should add **one** Coimbatore page only with real local projects/clients; no city farm |
| Entity | Brand name collides with MyLogin; needs LinkedIn, GitHub, Google Business Profile, directory profiles |
| Technical | Competitors rely on directory backlinks (Clutch, DesignRush); MyLoginn has none verified |

Do not copy competitor copy. Differentiators we can truthfully claim: combined build + testing + AI + training under one company, real shipped projects, in-house learning platform.

**How MyLoginn can legitimately beat them:** (1) real case studies with named live projects (most rivals use generic claims); (2) one entity covering build + test + AI + training; (3) fast, SSR site with correct schema; (4) honest FAQs (no guaranteed rankings or fake ratings); (5) third-party profiles (Clutch, GoodFirms, DesignRush, LinkedIn) built from real clients. Ranking above them is not guaranteed; (5) is the biggest current gap and cannot be done in code.

## Decisions from Round 3
1. Prioritise Pollachi, Udumalpet, Palani, Dindigul, Erode (low competition) over Coimbatore (crowded).
2. A Playwright course/page is the single best differentiator, only if you offer it.
3. Off-page: GoodFirms, TechBehemoths, DesignRush, Clutch, IndiaMART, YourStory, Sortlist profiles with real details, and Google Business Profile.
4. Keep local terms only in metadata/schema and the one Tamil Nadu page, per owner preference. No hidden on-page text.

## Decisions from Round 4
1. Karnataka, Kerala and the other states are served by the national pages; do not create state or city pages without real clients there (doorway risk, and competitors' city pages are weak on substance).
2. Win on proof, not volume: case studies, Google reviews and directory profiles. Competitors (OneCity, DigiMark) lead with reviews.
3. Zartek publishes `llms.txt` and targets AI + mobile in Kerala; MyLoginn already has `llms.txt` and an AI page, so match it with case studies.
4. Cost transparency wins informational traffic (PerfectionGeeks publishes ₹ ranges); publish MyLoginn's own real ranges.
